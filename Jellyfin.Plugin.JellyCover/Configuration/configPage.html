JellyCover · Hardcover.app metadata

Fetches book metadata and covers from Hardcover.app, plus author biographies and photos. Enable Hardcover as a metadata downloader and image fetcher in your Book library settings after saving a token here.

API token

Create a personal access token at hardcover.app/account/api/keys/new with the read:catalog scope (that link pre-selects it). Pick a long expiration; the plugin stops working when the token expires. Pasting the value with a leading "Bearer " is fine.

Books

The book's cover plus the covers of its most popular editions.
0 = no limit.
Hardcover's 0–5 average is scaled to Jellyfin's 0–10.

Matching

Books with a Hardcover id (set via Identify) or an ISBN (from an OPF / embedded metadata) are always matched exactly. Turn this off to only ever use exact matches during scans.
Calibre writes one for every book. It gives the exact title, author, ISBN and ASIN, which beats the truncated "Title - Author" file names Jellyfin otherwise searches with. The author is also used to score search hits.
